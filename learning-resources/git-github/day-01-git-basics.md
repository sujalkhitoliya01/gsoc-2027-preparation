
# Day 01 - Git Basics

## 1. What is Git?
Git is a Version Control System (VCS) used to track changes in files and manage different versions of a project.

## 2. Git vs GitHub vs GitHub Desktop

- **Git:** Tracks changes in code and files.
- **GitHub:** Online platform to store and collaborate on repositories.
- **GitHub Desktop:** A graphical application to manage Git operations.

## 3. Important Git Concepts

| Concept | Meaning |
|---|---|
| Working Directory | Where we create and edit files |
| Staging Area | Where we select changes for the next commit |
| Commit | Saves a snapshot of selected changes |
| Push | Uploads local commits to GitHub |
| Pull | Downloads and integrates updates from GitHub |
| Clone | Creates a local copy of a remote repository |

## 4. Git Workflow

1. Create or edit files.
2. Stage the changes.
3. Commit the changes.
4. Push commits to GitHub.
