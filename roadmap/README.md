# Preparation Roadmap

A flexible roadmap, not a guarantee of selection. Adjust it to official program dates and organization guidance.

## Phase 1 — Foundations
- Python fundamentals and regular coding practice
- Git/GitHub workflow
- Basic DSA and debugging

## Phase 2 — Explore
- Research organizations and codebases
- Compare project ideas and required skills
- Join community channels and understand norms

## Phase 3 — Contribute
- Set up selected repositories
- Start with scoped beginner issues
- Submit focused PRs and learn from reviews

## Phase 4 — Proposal preparation
- Study official proposal guidance
- Discuss scope with the community
- Draft milestones, deliverables, risks, and timeline
