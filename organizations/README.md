# Organization Research

Research organizations using official GSoC and project documentation. Do not assume an organization will participate in 2027 until officially confirmed.

## Research checklist
- [ ] Organization is listed for the relevant official program year
- [ ] Project and technology stack match my interests
- [ ] Contribution guide and communication channels are clear
- [ ] Development environment can be set up
- [ ] Beginner-friendly issues or starter tasks exist
- [ ] Project ideas and mentor expectations are understood

Use [organization-template.md](organization-template.md) for each candidate.
