# Contributing

This repository documents one learner's preparation journey. Suggestions and corrections are welcome.

## Guidelines
- Keep notes accurate, concise, and practical.
- Prefer official documentation as the source.
- Include links and access dates for time-sensitive information.
- Do not claim an issue, contribution, or achievement that has not happened.
- Use clear commit messages and focused changes.

## Suggested commit style
- `docs: add Python functions notes`
- `learn: record first Git branching exercise`
- `track: update weekly progress`
