# GSoC 2027 Preparation

My structured journey towards **Google Summer of Code (GSoC) 2027**.

This repository tracks my learning, open-source research, first contributions, projects, and weekly progress. The goal is to build real skills and make meaningful contributions—not just collect certificates.

## Current focus
- Strengthen Python and C++ fundamentals
- Learn Git, GitHub, and collaborative workflows
- Understand open-source contribution practices
- Explore organizations and their projects
- Start with beginner-friendly issues and build toward meaningful pull requests

## Repository structure
| Folder | Purpose |
|---|---|
| [learning-resources](learning-resources/) | Python, Git/GitHub, open-source and problem-solving notes |
| [organizations](organizations/) | Organization research, tech stacks and project shortlists |
| [contributions](contributions/) | Issues, pull requests and contribution logs |
| [roadmap](roadmap/) | Monthly plan, weekly goals and daily progress |
| [project-ideas](project-ideas/) | Practice projects and open-source project ideas |
| [notes](notes/) | Concepts, commands, mistakes and learnings |

## How I will use this repo
1. Learn a concept and write concise notes.
2. Practise it with a small task or project.
3. Research GSoC organizations and read their contribution guides.
4. Set up projects locally and understand their code.
5. Make small, useful contributions and document every PR.
6. Review progress every week and adjust the plan.
